# AI-Study-2026

**A structured learning journey in Python, algorithms, and AI development.**

这是我的个人计算机与人工智能学习仓库，主要用于记录 Python、数据结构与算法、计算机基础以及 AI 应用开发方面的学习与实践。

目标是通过持续学习、代码练习和项目实践，逐步建立扎实的软件开发基础。

## 🎯 Learning Goals

- 掌握 Python 编程与常见数据结构、算法
- 提升独立分析问题、编写代码和调试程序的能力
- 学习机器学习、深度学习和 LLM 应用开发
- 通过实际项目积累软件工程经验
- 为 AI 应用开发相关实习做好准备

## 📝 Learning Workflow

我的学习采用 Day / Week 的组织方式：

- **Daily Practice**：学习知识点，动手编写代码并进行复盘
- **Weekly Review**：每 7 天为一个学习周期，整理本周知识和易错点
- **Version Control**：通过 Git 记录代码和笔记的变化
- **Knowledge Management**：通过 Obsidian 整理学习笔记及知识关联
