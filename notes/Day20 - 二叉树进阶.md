# 二、LeetCode 543. 二叉树的直径


## 1. 题目理解

二叉树直径：

> 任意两个节点之间最长路径的边数。


例如：

```
        1
       / \
      2   3
     /
    4
```

最长路径：

```
4 -> 2 -> 1 -> 3
```

边数：

```
3
```

答案：

```
3
```


---

# 2. 核心思想


对于任意节点：

经过该节点的最长路径：

```
左子树高度 + 右子树高度
```

例如：

节点 1：

```
左高度 = 2
右高度 = 1
```

路径：

```
2 + 1 = 3
```

---

但是：

递归函数不能返回直径。

因为父节点需要知道：

```
子树高度
```

所以：

## dfs 返回：

```
当前节点高度
```

## 额外保存：

```
最大直径
```

---

# 3. 后序遍历


计算当前节点前：

必须先知道：

```
左高度
右高度
```

所以顺序：

```
左
↓
右
↓
根
```

即：

```
Left -> Right -> Root
```

---

# 4. 代码模板

```python
self.diameter = 0

def dfs(node):

    if node is None:
        return 0


    left_height = dfs(node.left)

    right_height = dfs(node.right)


    self.diameter = max(
        self.diameter,
        left_height + right_height
    )


    return 1 + max(
        left_height,
        right_height
    )
```

最后：

```python
dfs(root)

return self.diameter
```

---

# 5. 重点理解

递归返回：

```python
height
```

维护：

```python
diameter
```

也就是：

```
递归返回辅助信息
+
额外维护答案
```

# 三、LeetCode 110. 平衡二叉树


## 1. 什么是平衡二叉树？

定义：

对于任意节点：

```
左右子树高度差 <= 1
```

公式：

```python
abs(left_height - right_height) <= 1
```

---

例如：

平衡：

```
      1
     / \
    2   3
```

高度差：

```
|1-1|=0
```

---

平衡：

```
      1
     /
    2
```

高度差：

```
|1-0|=1
```

---

不平衡：

```
      1
     /
    2
   /
  3
```

高度差：

```
|2-0|=2
```

---

# 2. 核心思想

同样使用 DFS。

但是：

返回值有两个含义。


正常：

```
返回高度
```


异常：

```
返回 -1
```

表示：

```
发现不平衡
```

---

# 3. 状态传递


如果左子树已经不平衡：

```python
left_height == -1
```

那么：

当前节点一定不平衡。

直接：

```python
return -1
```


右子树同理。

---

# 4. 代码模板


```python
def dfs(node):

    if node is None:
        return 0


    left_height = dfs(node.left)

    if left_height == -1:
        return -1


    right_height = dfs(node.right)

    if right_height == -1:
        return -1


    if abs(left_height - right_height) > 1:
        return -1


    return 1 + max(
        left_height,
        right_height
    )
```

主函数：

```python
return dfs(root) != -1
```
