# Day24 - NumPy索引、切片与广播

## 一、今日学习目标

- 布尔索引
    
- 数组切片
    
- 多条件筛选
    
- NumPy 广播机制
    

## 二、布尔索引

布尔索引用于根据条件筛选数组元素。

```
import numpy as np

arr = np.array([10, 20, 30, 40, 50])

result = arr[arr > 25]
print(result)
```

输出：

```
[30 40 50]
```

原理：

1. `arr > 25` 逐个判断元素是否满足条件。
    
2. 得到布尔数组。
    
3. 只保留条件为 `True` 的元素。
    

## 三、数组切片

切片可以截取数组的一部分。

```
arr = np.array([10, 20, 30, 40, 50, 60])

print(arr[2:5])
```

输出：

```
[30 40 50]
```

规则：

- 包含起始下标。
    
- 不包含结束下标。
    
- 下标从 0 开始。
    

## 四、多条件筛选

使用 `&` 表示并且，使用 `|` 表示或者。

```
arr = np.array([8, 12, 20, 30, 45, 50])

result = arr[(arr >= 20) & (arr < 50)]
print(result)
```

输出：

```
[20 30 45]
```

注意：每个条件都需要用括号括起来。

## 五、广播机制

广播允许 NumPy 对形状兼容的数组进行运算。

### 1. 标量广播

```
arr = np.array([10, 20, 30])
print(arr + 5)
```

输出：

```
[15 25 35]
```

### 2. 一维数组与二维数组运算

```
arr = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

b = np.array([100, 200, 300])

print(arr + b)
```

输出：

```
[[101 202 303]
 [104 205 306]]
```

一维数组会应用到二维数组的每一行。

### 3. 广播规则

从两个数组形状的最后一维开始比较：

- 两个维度相等，可以兼容。
    
- 其中一个维度为 1，可以兼容。
    
- 缺少的维度按 1 处理。
    
- 如果某个维度既不相等，也没有维度为 1，则不能广播。
    

例如：

```
(2, 3) 和 (2, 1) → 可以广播
(2, 3) 和 (3,)   → 可以广播
(2, 3) 和 (2,)   → 不能广播
```

## 六、今日综合练习

```
import numpy as np

arr_1 = np.array([10, 20, 30, 40, 50, 60])

# 1. 筛选大于等于30的元素
result_1 = arr_1[arr_1 >= 30]

# 2. 截取下标1到3的元素，不包含3
result_2 = arr_1[1:3]

# 3. 将[1, 2, 3]加到二维数组的每一行
matrix = np.array([
    [10, 20, 30],
    [40, 50, 60]
])

result_3 = matrix + np.array([1, 2, 3])

print(result_1)
print(result_2)
print(result_3)
```

输出：

```
[30 40 50 60]
[20 30]
[[11 22 33]
 [41 52 63]]
```

## 七、今日总结

1. 布尔索引：按照条件筛选元素。
    
2. 切片：截取数组的一部分，遵循左闭右开原则。
    
3. 多条件筛选：使用 `&`、`|`，并给每个条件加括号。
    
4. 广播：允许形状兼容的数组进行运算。
    
5. 判断广播兼容性时，从最后一维开始比较。
