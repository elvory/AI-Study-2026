# Day27 - 机器学习基础概念

## 一、什么是机器学习？

机器学习是让计算机从数据中学习规律，并利用学到的规律对新数据进行预测或判断。

基本流程：

数据 → 训练模型 → 学习规律 → 预测新数据

例如：根据历史房屋的面积、楼层和成交价格，预测新房屋的价格。

## 二、监督学习与无监督学习

### 1. 监督学习（Supervised Learning）

训练数据包含输入信息和对应的正确答案（标签），模型通过学习样本建立预测规律。

例子：

- 根据房屋面积预测房价。
    
- 根据邮件内容判断是否为垃圾邮件。
    
- 根据图片识别猫或狗。
    

### 2. 无监督学习（Unsupervised Learning）

训练数据没有预先提供的目标标签，模型尝试发现数据中的结构或规律。

例子：

- 根据用户消费习惯对用户进行分组。
    
- 根据数据相似性进行聚类。
    

记忆：

- 监督学习：有标签，学习预测。
    
- 无监督学习：无预设标签，寻找规律。
    

## 三、特征与标签

### 1. 特征（Feature）

用于预测的输入信息，通常记作 X。

例如房价预测中的：

- 房屋面积
    
- 房间数量
    
- 所在楼层
    

### 2. 标签（Label）

监督学习中需要预测的目标，通常记作 y。

例如：

- 房屋价格
    
- 邮件是否为垃圾邮件
    
- 图片所属类别
    

基本关系：

特征 X → 模型 → 预测结果 y

## 四、训练集与测试集

### 1. 训练集（Training Set）

用于训练模型，让模型学习数据中的规律。

### 2. 测试集（Test Set）

用于评估模型在未参与训练的数据上的表现。

例如，将 1000 条数据划分为：

- 800 条训练数据
    
- 200 条测试数据
    

常见划分比例为 8:2，但不是固定要求。

### 3. 过拟合（Overfitting）

如果模型在训练集上表现很好，但在测试集上表现明显较差，可能存在过拟合。

### 4. 泛化能力（Generalization）

模型处理未见过的新数据的能力。

注意：测试集应保持独立，不能用测试结果反复调节模型后再把它当作独立评估结果。

## 五、回归与分类

### 1. 回归（Regression）

预测连续数值。

例子：

- 房价预测
    
- 气温预测
    
- 考试分数预测
    

### 2. 分类（Classification）

预测数据所属的类别。

例子：

- 猫或狗的图片识别
    
- 垃圾邮件识别
    
- 判断用户是否违约
    

记忆：

- 回归：预测数值。
    
- 分类：预测类别。
    

## 六、综合例子

任务：使用已经标注猫和狗的图片训练模型，判断新图片属于哪一类。

分析：

- 监督学习：训练图片有标签。
    
- 分类任务：预测结果是猫或狗。
    
- 特征：图片中的像素及其可学习的特征表示。
    
- 标签：猫或狗。
    

## 七、今日总结

1. 机器学习让模型从数据中学习规律。
    
2. 监督学习使用带标签的数据进行训练。
    
3. 无监督学习尝试发现数据中的结构。
    
4. 特征 X 是输入信息，标签 y 是预测目标。
    
5. 训练集用于学习，测试集用于独立评估。
    
6. 过拟合意味着模型可能过度适应训练数据。
    
7. 回归预测数值，分类预测类别。
