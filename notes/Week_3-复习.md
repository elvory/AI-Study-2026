## 二、核心知识复盘

|知识点|核心思想|
|---|---|
|数组|下标随机访问 O(1)|
|哈希|dict / set 平均查找 O(1)|
|双指针|左右指针、快慢指针|
|滑动窗口|扩大、缩小连续区间|
|栈|LIFO，后进先出|
|队列|FIFO，先进先出|
|链表|通过 next 连接节点|
|二分查找|每次排除一半搜索范围|
|递归|终止条件 + 子问题 + 返回值|
|DFS|深度优先，递归或栈|
|BFS|广度优先，通常使用队列|

## 三、二叉树遍历

- 前序：根 → 左 → 右
    
- 中序：左 → 根 → 右
    
- 后序：左 → 右 → 根
    
- BFS：从上到下逐层遍历
